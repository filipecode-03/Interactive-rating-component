# ⭐ Interactive Rating Component – Frontend Mentor Challenge

### 📌 About the Project

This project is an **interactive rating component**, developed as part of a **Frontend Mentor** challenge.  
The goal was to recreate the provided design and implement user interaction, allowing users to select a rating and view a confirmation state.
The application was built using **React.js** for component logic and state management, **Vite** for a fast development environment, and **Tailwind CSS** for utility-first styling.

### 🛠️ Technologies Used

[![My Skills](https://skillicons.dev/icons?i=react,vite,tailwind,html,js)](https://skillicons.dev)

### 🧠 Learnings

During the development of this project, it was possible to:

- Practice **component-based architecture** with React.
- Work with **state management** to handle user interactions.
- Implement conditional rendering based on application state.
- Use **Tailwind CSS** to build responsive and consistent UI layouts.
- Improve workflow efficiency using **Vite** as a build tool.
